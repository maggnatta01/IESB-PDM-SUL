# Prática 08 - Gerenciador de Despesas

Aplicativo React Native que expande a navegação da Prática 07 com categorias, validação do cadastro, resumo financeiro e filtro dinâmico das despesas.

O projeto independente está em [`GerenciadorDespesas/`](GerenciadorDespesas/). Consulte o [README do projeto](GerenciadorDespesas/README.md) para instalar as dependências, executar o Expo e conhecer os componentes.
