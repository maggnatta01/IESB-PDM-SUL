# MeuDiarioAcademico

Aplicativo introdutório em React Native com Expo para visualizar uma lista estática de disciplinas do semestre e praticar a composição de uma tela de cadastro rápido.

Esta atividade demonstra:

- Core Components do React Native;
- `import` e `export`;
- estilos com `StyleSheet`;
- organização com Flexbox;
- uso de largura percentual;
- uso de `flex`.

## Como executar

O projeto pode ser criado com:

```bash
npx create-expo-app@latest MeuDiarioAcademico --template blank
```

Na pasta `pratica04`, instale as dependências e inicie o Expo:

```bash
npm install
npx expo start
```
